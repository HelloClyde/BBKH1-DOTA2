# 对局结算和历史记录

对局结束后展示十名英雄的等级、K/D/A、补刀/反补和净资产，并标出 MVP。
点一行查看该英雄的伤害、建筑伤害、有效友方治疗和最终装备，包含背包、
中立装备及独立传送卷轴。方向键选择英雄，D 查看详情，Enter 再战，
R 打开历史，Esc 返回；触摸使用页面下方按钮。

主菜单的“历史对局 R”查看最近 **50 局完成的对局**，每页八条。A/D 或
左右键翻页，上下键选记录，Enter 打开十人战绩，再按 Enter 查看所选英雄
详情。离开历史不会开始新对局。赛前倒计时不计入记录的比赛时长。

只有遗迹胜负确定的完成对局会入库。暂停、看结算、看历史或重复返回结算
不会增加记录；中途回菜单或退出应用的未完成对局不生成一场胜负。

## 本地 MVP

本项目评选胜方的一位 MVP，采用可复核的本地贡献公式：

`击杀×300 + 助攻×200 + 敌方英雄实际伤害÷20 + 建筑实际伤害÷10 + 有效友方治疗÷15 + 参战率×500 − 阵亡×75`

参战率为 `(击杀+助攻)/本队总击杀`，最高 100%，本队没有击杀时记 0。
计分使用整数并做饱和处理。同分依次比较更少阵亡、更多助攻、更多英雄
伤害、较小英雄槽位。治疗只统计确实增加其他友方英雄生命值的部分，
不把自身回血、溢出治疗、泉水或自然恢复计为友方治疗贡献。

这是 H1 离线版的本地算法，不是 Valve 的 MVP 算法。净资产也是本地
所有权估值：金币加当前物品和信使待送物品的目录价格，卷轴按独立数量
计价；详情用 NW 标记，不将它描述为 Valve 完整经济统计。

## 存档

优先使用 `B:\DOTA2\MATCH0.H1S` 和 `B:\DOTA2\MATCH1.H1S`，备用路径为
`A:\DOTA2.HS0` 和 `A:\DOTA2.HS1`。这些是可写战绩存档，独立于只读素材
`DOTA2.H1R`，更新素材时保留它们。

每个快照 52,064 字节，包含显式小端格式、版本、序号和 CRC。新记录写入
非当前有效槽，关闭后重新读取并校验完整快照，验证成功才切换当前槽。
载入时选择校验通过且序号最新的快照，损坏或短写的槽不会代替有效旧槽。
这不构成对存储卡损坏或掉电行为的保证。

保存失败时结算和历史仍可查看内存中的记录，并显示 `SAVE ERROR`；在结算
按 S 重试。重试同一场不会重复入库。请在确认保存成功后退出，存档失败
时未提交的记录不会被描述为已保存到设备。

历史缓冲和序列化工作区使用固件动态内存，共 54,096 字节（约 52.8 KiB）；逐块读写时仍服务
音频。退出应用后释放这些内存和文件句柄。
