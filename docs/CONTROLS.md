# H1 操作

v0.30配套资源为 `B:\DOTA2\DOTA2.H1R`（112,861,448字节），需与新BDA一起更新。包内包含SCENE、SOUND、VISION和TREE四个逻辑流，无须分别复制旧五个素材文件。本轮还加入独立卷轴格、双击自施法、走近施法及十人结算/历史；最终H1功能和帧率验收仍待独立实测。

对局中按 BACK 或 P 打开暂停菜单，再选“帮助 H”查看键位；主菜单也可按 H 或点击“操作帮助”。轻点与拖动分别处理；拖动画面不会同时发出英雄移动命令。

普通小地图操作只改变镜头；已经明确选择技能或物品目标时，小地图仍可给点地技能和传送等指定目标。点地与指向技能不会因按下技能键就自动挑选附近敌人。无目标主动技能直接施放。

合法目标超出技能或物品距离时，先提交走近施法动作，进入范围后才执行并扣蓝/启动冷却。走近期间仍受原地形、建筑和视野规则约束；目标失效、新移动或停止等指令会取消待执行动作。并非所有指向物品都可以对自己使用，双击不会绕过队伍、目标类型或状态限制；合并眼的同键操作仍用于切换两类眼。

独立卷轴在战场使用G；商店中的G仍是“升级去向”。结算和历史详情包含六格装备、三格背包、中立装备和独立卷轴。仅保存最近50局完成对局；暂停、重复查看结算或中途退出不新建一场。MVP为胜方优先的本地贡献评分，不是Valve算法。双槽路径、恢复边界和评分说明见[对局记录](MATCH-HISTORY.md)。

帮助只在选择后打开。暂停中的帮助、商店和技能页关闭后仍保持暂停；帮助中点击说明正文不会关闭页面或恢复对局。从主菜单进入帮助，则返回主菜单。“版权介绍”列出作者 HelloClyde、Valve / Dota 2 原始版权及代码、SDK、字形的不同权属。

## v0.29 砍树与吃树

在六格装备中选择树之祭祀、压制之刃或狂战斧，按对应装备键或点图标进入瞄准，再点要处理的树冠；程序按离线树冠像素确定原树实体。键盘可用方向键把目标移到树干附近，Enter确认，Esc取消。超出物品施法距离或没有有效树时不消耗次数、不启动冷却。

树之祭祀会吃掉目标树并获得恢复效果；吃铁树枝种出的临时树保留对应加成。原地图可交互树倒下后更新画面、通行和视线，180秒游戏时间后重生；临时树按其自身期限消失。暂停和商店中这些计时冻结。

树资源现包含在统一包的TREE逻辑流中。v0.29的独立 `TREE.H1T` 安装方法不再适用于本版；不要仅换BDA而遗漏新的 `DOTA2.H1R`。

商店打开期间对局时间、单位、技能冷却和信使运输暂停。下单会立即扣金，远离泉水时货物由信使在恢复对局后运输；泉水购买可直接入库存。英雄推荐为本版购物辅助，未声称最新竞技出装。

技能等级以图标下方黄色短线表示。四格技能行保持原宽；出现额外技能后五格共享同一宽度，Q/W/E/R/T 放在主动图标左上角，血蓝条与恢复值仍在下方。

## v0.28 插眼与合并眼

眼放在六格装备中时，按对应 Z/X/C/V/B/N 或短点图标进入点地瞄准；显示当前选中的单眼图标/名称、放置距离及标称视野或真视圈。用 Enter 或点地确认，Esc 取消。背包里的眼须先移回装备栏。

合并眼在两类都有库存时默认选侦察守卫；只有岗哨时自动选岗哨。瞄准期间再按同一个装备键，或短点同一个图标，切到另一个仍有库存的类型，保留瞄准位置；切换本身不消耗。只有实际成功放置才扣数量，无库存的类型不能放置。

目标位于原地图禁插区时，预览变红并显示“此处不能放置”；点击或 Enter 失败后保留瞄准和当前目标点，不扣次数、不启动冷却。两队的侦察眼、岗哨眼及合并眼均使用同一判定。五个禁区来自原地图凸包：两处泉水、两处肉山区及另一处小禁区，按二维投影适配；没有把泉水回血圈或寻路不可行走区域当作禁区，合法的高眼位仍可放置。

超出施法距离也显示红色预览，并单独提示“目标超出施法距离”；标称视野圈与放置距离分别显示。

标称范围圈不等于每点都可见，实际视线仍受树木和分层高地近似遮挡。赛前从−1:00倒计时至号角0:00；日夜每阶段300秒，暂停和商店仍冻结这些计时。

岗哨只提供真视检测，本身不提供普通地面视野；隐形目标仍需处于团队已有的地面视野中。界面所画的范围是标称圈，不能绕过树木/高地遮挡。

VISION的139,328字节视野数据已无损收入统一包，不再要求设备单独放置 `VISION.H1V`。资源缺失或校验失败时应补齐匹配的 `DOTA2.H1R`；旧版独立VISION文件不能替代本版统一包。
