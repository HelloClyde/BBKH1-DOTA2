# H1 操作

所有键位也可在对局中按 BACK 或 P 打开的暂停页查看。轻点与拖动分别处理；拖动画面不会同时发出英雄移动命令。

| 操作 | 按键 / 触摸 |
| --- | --- |
| 选择英雄、开始 | 方向键、Enter / 确定，或点选英雄与开始按钮 |
| 英雄移动、攻击 | 方向键；点空地移动、点敌人追击攻击；J 普攻、K 停止 |
| 镜头平移 | 拖动战场；点按或拖动小地图快速切换；A/S/D/F 左/下/右/上 |
| 回到英雄 | SPACE，或点击下方英雄属性/血蓝状态区 |
| 四个基本技能 | Q/W/E/R 或短点图标；被动无施法键 |
| 额外技能 / 模式 | T 或第五格图标；获得对应魔晶/神杖能力后出现，屠夫喷吐为临时能力 |
| 确定技能目标 | 单位技能点有效单位，点地技能点位置；键盘方向键调整瞄准，Enter 确认，Esc 取消 |
| 加点、先天、天赋 | U 打开技能页；QWER 加点、方向选择、Enter 确认、I 看说明；对局中 Shift+QWER 快速加点 |
| 主动装备 | Z/X/C/V/B/N，对应六格；Y 使用中立主动；需要目标的物品同样先瞄准 |
| 换装备位置 | 长按图标约 450 毫秒再拖动、松开换位；或 I 进入换位后用方向键和 Enter，Esc 取消 |
| 战绩 | H 或点左上 KDA；再次 H / Esc 或表外点击收起 |
| 莲花、地图设施 | L 使用莲花；点莲花池、祭坛或侦察眼后走近交互 |
| 商店 | M 或右下按钮；方向键选物品，Enter 下单；M / Esc / BACK 关闭 |
| 商店分类、详情 | Q/W 切分类、翻页键翻页，I 看说明和配方 |
| 快速购买眼 | 商店 L 或标题栏“眼 L”；在侦察/岗哨之间切换，Enter 购买 |
| 英雄推荐 | 商店中 T 进入推荐页，A/D 或触摸按钮切出门/前期/核心/可选 |
| 装备升级去向 | 商店中 G 或点击“升级去向”；选择真实配方的合成目标后 Enter 购买 |
| 出售、拆解 | 商店中 Z/X/C/V/B/N 选对应装备出售，Shift 加对应键尝试拆解 |
| 暂停、恢复 | 对局中 BACK / P / 右上暂停；暂停中 BACK / P / Enter / Esc 恢复 |
| 暂停内查看 | M 商店、U 技能页；关闭后仍回到暂停 |
| 退出应用 | 暂停页 X 或“退出应用”按钮；主菜单 BACK 可退出 |

普通小地图操作只改变镜头；已经明确选择技能或物品目标时，小地图仍可给点地技能和传送等指定目标。点地与指向技能不会因按下技能键就自动挑选附近敌人。无目标主动技能直接施放。

商店打开期间对局时间、单位、技能冷却和信使运输暂停。下单会立即扣金，远离泉水时货物由信使在恢复对局后运输；泉水购买可直接入库存。英雄推荐为本版购物辅助，未声称最新竞技出装。

技能等级以图标下方黄色短线表示。四格技能行保持原宽；出现额外技能后五格共享同一宽度，Q/W/E/R/T 放在主动图标左上角，血蓝条与恢复值仍在下方。

## v0.28 插眼与合并眼

眼放在六格装备中时，按对应 Z/X/C/V/B/N 或短点图标进入点地瞄准；显示当前选中的单眼图标/名称、放置距离及标称视野或真视圈。用 Enter 或点地确认，Esc 取消。背包里的眼须先移回装备栏。

合并眼在两类都有库存时默认选侦察守卫；只有岗哨时自动选岗哨。瞄准期间再按同一个装备键，或短点同一个图标，切到另一个仍有库存的类型，保留瞄准位置；切换本身不消耗。只有实际成功放置才扣数量，无库存的类型不能放置。

目标位于原地图禁插区时，预览变红并显示“此处不能放置”；点击或 Enter 失败后保留瞄准和当前目标点，不扣次数、不启动冷却。两队的侦察眼、岗哨眼及合并眼均使用同一判定。五个禁区来自原地图凸包：两处泉水、两处肉山区及另一处小禁区，按二维投影适配；没有把泉水回血圈或寻路不可行走区域当作禁区，合法的高眼位仍可放置。

超出施法距离也显示红色预览，并单独提示“目标超出施法距离”；标称视野圈与放置距离分别显示。

标称范围圈不等于每点都可见，实际视线仍受树木和分层高地近似遮挡。赛前从−1:00倒计时至号角0:00；日夜每阶段300秒，暂停和商店仍冻结这些计时。

岗哨只提供真视检测，本身不提供普通地面视野；隐形目标仍需处于团队已有的地面视野中。界面所画的范围是标称圈，不能绕过树木/高地遮挡。

v0.28必须在B:\DOTA2\放入匹配的VISION.H1V（139,328字节）。缺失、损坏或视野内存无法分配时会显示资源错误15并阻止进局；BACK退出后补齐文件。原三个大素材哈希一致即可保留，不要只更新BDA而遗漏VISION。
