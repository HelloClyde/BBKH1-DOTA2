# v0.30 资源重整说明

本轮把原来五个运行资源包整理成一个 `DOTA2.H1R`：

| 项目 | 字节数 |
|---|---:|
| v0.29 五包合计 | 450,526,944 |
| 新统一包 | 112,861,448 |
| 减少 | 337,665,496（74.95%） |

这来自无损压缩、重复像素数据共用，以及去掉重复地图缓存。英雄动作、
技能、水面、泉水、建筑补丁和可砍树效果都保留。未通过删帧、缩分辨率或
降低颜色精度缩小体积。

原动画包中有 4,349 个完全重复的帧像素负载，共约 39.94 MB；新包允许
不同动作引用同一份像素，同时各自保留方向、锚点和播放信息。原 `MAP12`
又存了一份与 `SCENE` 相同的地图，新包直接读取压缩后的地图，不再另存
这份 16.59 MB 副本。

树仍保留每个实例的实际位置、外观、树桩和遮挡深度。内部采用稀疏表示，
全部 364 个有效瓦片还原出的原始树层数据逐字节相同；并按瓦片连续分块，
减少碎片读取。原 17.5 MB 树包和其历史验证记录保留为离线来源。

音乐和音效在新包中保持原始连续区段，不做二次压缩，也不改 PCM 来源、
曲目和音量规则。地图和动画的每个解码块最多 16 KB，读取器可以在块间
维护音频服务；目录按页读取，无须把整个包或整份目录装进内存。

离线转换已从新包完整还原并核对四个逻辑流：原 `SCENE`、原 `SOUND`、
原 `VISION` 的完整 SHA-256 相同；稀疏树流与其已验证的 v2 来源相同。
新读取器、最终 BDA 和 H1 真机验收由独立报告记录；本说明不把体积缩小
当作帧率提升，也不提前宣称真机测试通过。

来源、完整哈希、目录规范和复现命令见
[资源审计记录](../provenance/resource-v030/README.md)及
[二进制格式](../tools/resource_pack_format.md)。普通构建直接使用统一包；
重新转换旧包须具备保存的历史输入，重新烘焙原游戏素材还需要原始资源。
